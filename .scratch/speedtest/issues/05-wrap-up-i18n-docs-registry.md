## Comments

### 应用内人工巡检清单(2026-09-30,implementer 产出)

前置:正常订阅配置、有可用节点;设置 → 杂项里可见「速度测试链接」「速度测试时长」。逐项执行,全部符合预期即通过。

1. **单项测速**
   - 操作:代理页任选一个节点,悬停后点击速度测试按钮(节点悬停区,延迟按钮旁)。
   - 预期:该节点立即进入测量中状态(加载动画);测速窗口(默认 5 秒)结束后,节点右侧速度数值常驻显示,格式为 KB/s 整数或 MB/s 一位小数;同分组内其他节点不受影响。
2. **整组测速与逐个刷新**
   - 操作:分组头部(列表视图与卡片视图各试一次)点击整组速度测试按钮。
   - 预期:组内节点逐个串行进入测量中,每完成一个立即更新显示,不是全部结束后才刷新;嵌套子组与 provider 订阅节点同样可测;测速期间可再次点按钮重新触发全组。
3. **速度排序与持久化**
   - 操作:分组头部点击排序图标,循环切到「按下载速度排序」;切换代理页其他分组后再回来;完全退出应用重进。
   - 预期:有速度结果的节点降序排列,无结果节点排最后;排序档选择被记住(重进后仍为速度排序);速度与延迟、名称、默认四档循环切换正常。
4. **设置项生效与兜底**
   - 操作:杂项设置中把测速时长改为 2 秒,把测速链接改为一个明确可达的大文件地址,各测一次;再把链接清空、时长清空或填越界值(如 0、99),再测。
   - 预期:2 秒窗口明显更快出结果,自定义链接生效;空白或越界输入时回落内置默认(URL 用内置测试文件、时长 5 秒),测速仍能完成。
5. **测速期间分组选择与正常上网不受扰**
   - 操作:确认某分组当前选中节点 A 并保留手动选择记录;对该分组整组测速;测速期间用系统代理正常浏览网页。
   - 预期:整组测速结束后该分组选中的仍是 A,网页浏览走 A 不中断;测速完成后重载配置或重启,选择仍为 A(不被 GLOBAL 切换污染)。
6. **失败路径**
   - 操作 a:断网(或关掉节点对应的代理服务器)后对节点测速。
   - 预期 a:该节点显示失败状态,区别于未测试与测量中;整组测速不会因单节点失败而中断,后续节点继续。
   - 操作 b:把测速链接设为一个不可达地址(如不存在域名)后测速。
   - 预期 b:测速失败或速度为 0,应用不崩溃、不报未捕获错误;改回有效 URL 后可恢复。
7. **重启后速度清零与延迟一致**
   - 操作:测出若干速度结果后重启应用。
   - 预期:所有节点速度回到未测试状态(与延迟行为一致);再次测速可重新得到结果。
